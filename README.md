# 🧠 Os Quatro Temperamentos

Projeto Integrador da disciplina **Desenvolvimento Front-End para Web**.

Aplicação web interativa e responsiva que apresenta os quatro temperamentos clássicos — **Colérico, Sanguíneo, Melancólico e Fleumático** — e aplica um teste de 10 perguntas para mostrar com qual deles a pessoa mais se parece.

> ⚠️ O teste é **recreativo**. A teoria dos temperamentos é histórica e não é um diagnóstico nem uma avaliação psicológica científica.

---

## 🚀 Como executar

Abra o arquivo `index.html` em qualquer navegador (ou use a extensão **Live Server** do VS Code).

Não é preciso instalar nada: o projeto usa apenas HTML, CSS e JavaScript, sem bibliotecas.
